# BYNotes LaTeX web fonts

Modified WOFF2 subsets generated by `scripts/latex-notes/fonts.py` from the
local TeX Live 2026 distribution. Internal font names use the BYNotes prefix.

| Files                                      | Original fonts                      | License                              |
| ------------------------------------------ | ----------------------------------- | ------------------------------------ |
| termes-regular, termes-italic, termes-bold | TeX Gyre Termes (GUST/e-foundry)    | GUST Font License, included          |
| pagella-bold                               | TeX Gyre Pagella (GUST/e-foundry)   | GUST Font License, included          |
| song                                       | FandolSong Regular (Fandol project) | GPL v3 with font exception, included |
| kai                                        | FandolKai Regular (Fandol project)  | GPL v3 with font exception, included |

Source packages: `https://ctan.org/pkg/tex-gyre` and
`https://ctan.org/pkg/fandol`. Original copyright/license metadata is retained
inside the subsets. The font exception is retained for these modified Fandol
subsets. Generation preserves outlines and reduces glyph coverage; it does
not redesign the typefaces. The regeneration script and corpus instructions
are in `docs/latex-publishing-sop.md`.

Current corpus: Decision Theory source snapshot, SHA-256 of main.tex
`b587980e8fde0642cf3baaa9779d510280fead2bbc927f1919b8e89be495b547`, plus its
included TeX sources and basic interface characters. Add future note sources
to the corpus union before regenerating.

The 2026-11-04 release subset also includes the authorized corrected edition
`fae60c82d8ac5326cd33808d5d31a36e3fbccdf13798d8cb9b15fdddd5ef786b`.
