## Concept Map

- Linear prediction and regularization: OLS, locally weighted regression, ridge, LASSO, elastic net, and GLMs.
- Classification: logistic regression, perceptron, GDA, Naive Bayes, and SVM.
- Flexible regression: tree models, step functions, regression splines, and smoothing splines.
- Ensembles: voting, bagging, boosting, AdaBoost, and gradient boosting.
- Kernel methods: feature maps, kernel trick, RKHS, representer theorem, and kernelized regression.
